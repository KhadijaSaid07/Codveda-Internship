## Level 3 — Advanced

Focus: full-stack development, API integration, databases, and authentication.

### Task 1 — StudentHub Full-Stack CRUD

A student record management application with a React frontend, an Express backend, and PostgreSQL persistence.

Main areas:
- Student record management
- REST API integration
- PostgreSQL database operations
- JWT-protected student API routes

See the [Task 1 README](Task01/Level-3-Advanced/Task-1-Fullstack-CRUD/README.md).

### Task 2 — StudentHub Authentication API

An authentication service built with Node.js, Express, PostgreSQL, bcrypt, and JSON Web Tokens.

Main areas:
- User registration and login
- Secure password hashing
- JWT generation and verification
- Protected user profile endpoint
- Integration with the StudentHub student API

See the [Task 2 README](Task01/Level-3-Advanced/Task-2-Authentication/README.md).

## Running the Projects

Each project may have its own requirements and startup commands.

1. Open the directory for the task you want to run.
2. Read its README for the required software, installation steps, environment configuration, and run commands.
3. Configure local environment variables where required. Never commit real passwords, API secrets, JWT secrets, or `.env` files.
4. Start the frontend and backend separately when the project requires both.
