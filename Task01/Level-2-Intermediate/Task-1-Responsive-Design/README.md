# Level 2 — Task 1: Responsive Design

## Project
ZanziExplore is a responsive Zanzibar travel discovery webpage built with HTML5 and CSS3.

## Features
- Responsive navigation and hero section.
- Destination cards and experience sections.
- CSS Flexbox for navigation and flexible content alignment.
- CSS Grid for destination cards, experience layouts and the about section.
- Media queries for desktop, tablet and mobile screen sizes.
- Responsive images, accessible image descriptions and semantic HTML.
- Reduced-motion support for visitors who prefer less animation.

## Technologies
- HTML5
- CSS3 (Flexbox, Grid and media queries)

## Run locally
Open `index.html` in a browser. The project does not require a build tool.

## Images
The page uses image assets from the repository's shared `images` directory.
