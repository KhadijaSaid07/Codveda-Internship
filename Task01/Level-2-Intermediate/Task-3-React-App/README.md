# Khalsa360 Restaurant

A responsive restaurant website built with React and Vite.

## Features
- Responsive navigation and homepage
- Food menu with categories and filtering
- Food images and menu cards
- Restaurant services and About Us sections
- Contact section with email and WhatsApp links
- Responsive design for mobile and desktop

## Technologies
- React
- JavaScript
- Vite
- CSS

## Run Locally

npm install
npm run dev


## Build for Production


npm run build
